# Contributing to frontend-awesome

Thanks for helping keep this list awesome! A few simple rules keep it useful and easy to review.

## Adding a resource

- **One resource per pull request**, with a clear title like `docs: add <name>`.
- **Pick the right section** and keep it in **alphabetical order**.
- **Use this format**, with an `https` link and an optional short description:

  ```md
  - [Name](https://example.com) - Short description of what it does.
  ```

- **It must be useful to front-end developers** and actively maintained. Free tools or ones with a free tier are preferred.
- **Search before adding** so you don't add a duplicate.

## Updating or removing a resource

Links die and projects get abandoned. If you find a broken link, a tool that has shut down, or one that has been replaced by something better, open a pull request removing or updating it and explain why.

## New sections

If a resource doesn't fit any section, propose a new one in your pull request. Remember to add it to the **Contents** list in alphabetical order too.
